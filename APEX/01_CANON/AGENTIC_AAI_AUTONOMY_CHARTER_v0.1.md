# APEX Agentic AAI Autonomy Charter v0.1

## Mission
Build reusable APEX modules through governed software autonomy while Otto retains authority over consequential promotion and real-world action.

## Activated Authority

| Control | Activated Value |
|---|---|
| Autonomous ceiling | `A3_DRAFT_DELIVERY` |
| Runtime model | Hybrid: local package + GitHub Actions testing |
| Monthly compute/API ceiling | `USD 50` |
| Automated repair ceiling | `5 cycles per run` |
| Primary-source research | Allowed when it materially changes tests or decisions |
| Structured ledgers | Allowed |
| Draft PR creation | Allowed |

## Authorized Automatically

- Build non-sensitive specifications, code, schemas, tests, dashboards and packages.
- Run sandbox/local software tests and bounded repair cycles.
- Write evidence, failure, decision and resource ledgers.
- Create a public-safe GitHub branch and **draft pull request only**.
- Use primary-source research where it materially changes a test, risk or decision.

## Human Approval Required

- Merge, publication, release or production deployment.
- Budget increase above `USD 50/month`.
- Credentials, new sensitive access, or public upload of private/sensitive media.
- Change to APEX purpose, canon or authority rules.
- Physical connection, command, actuation or test.

## Hard Prohibitions in v0.1

No autonomous merge. No production deployment. No secrets in artifacts. No sensitive media in public paths. No authority self-escalation. No physical action.

## Terminal Decisions

`PROMOTE_TO_DRAFT_REVIEW`, `REPAIR`, `HOLD`, `BLOCK`, `ROLLBACK`, `RESEED`.

## Truth Boundary

This charter authorizes governed software building and draft-delivery activity only. It does not establish production readiness, physical autonomy or permission to handle secrets or private media publicly.
