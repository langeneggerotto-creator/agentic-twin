Truth Boundary

This console never downloads video or audio files and never bypasses platform login, paywalls, or terms of service. It reads only the public oEmbed metadata endpoint and the official caption/transcript track YouTube already serves for the video. Extracted quotes are checked against the transcript text automatically; items that fail that check are flagged unverified and should be confirmed against the source video before you rely on or republish them. Auto-generated captions can contain errors, and named laws/theories should be checked against a primary source.
