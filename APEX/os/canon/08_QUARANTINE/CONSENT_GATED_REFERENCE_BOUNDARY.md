# Consent-Gated Reference Quarantine Boundary

## Decision

A supplied C8 package contains private real-person reference material under a consent-gated media path. The OS imports the package's safe policy language, truth labels, consent/provenance gate and educational-anatomy boundary, but it does **not** place underlying real-person images into the global OS canon or automatic GitHub text-capture lane.

## Reason

Raw identity/likeness material requires explicit authorization, allowed-use scope, provenance, storage controls and publication approval before broader reuse.

## Allowed Now

- Register that a consent-gated media bundle exists.
- Preserve package hash and safe textual policy status.
- Apply its truth, consent and inference boundaries in relevant module planning.

## Held Until Separately Authorized

- Repository publication of raw person images.
- Likeness model deployment.
- Avatar publication or identity reconstruction.
- Any medical, psychological or private-state inference involving identifiable people.

## Automatic Capture Rule

The GitHub Auto-Capture lane must exclude raw real-person imagery, private/sensitive data and other consent-gated media by default. It may capture this boundary document and sanitized provenance metadata only.
