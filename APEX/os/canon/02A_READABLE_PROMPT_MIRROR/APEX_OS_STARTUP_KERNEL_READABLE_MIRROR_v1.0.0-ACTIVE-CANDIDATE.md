# APEX OS Startup Kernel — Human-Readable Mirror v1.0.0

## What Is Integrated

The OS receives a clean foundation: it begins from a truthful seed, learns through feedback, handles permanent uncertainty, and never increases autonomous action faster than governance can control it.

## What This Changes

| Area | Previous Condition | Integrated Direction |
|---|---|---|
| Bootstrap | Many module-specific ideas | One Genesis seed for lawful knowledge acquisition |
| Autonomy | Boundaries distributed across modules | One Safe Autonomy execution scale and stop logic |
| Visibility | Multiple dashboards and queues | APEX Mirror becomes the primary human control surface |
| Execution | Safe prototypes and orchestration concepts | Automator operates only within Mirror-visible authority |
| Evidence | Packages and capture paths | GitHub Auto-Capture becomes a governed OS continuity lane |
| Privacy | Consent rules present in scoped packages | Private real-person media formally excluded from general automatic ingest |

## Simple Meaning

```text
Learn continuously.
Act only within authority.
Show what is true.
Preserve evidence automatically when safe.
Stop when humans must decide.
```

## Permanent Operating Order

```text
Human Authority
→ Purpose
→ Genesis Dot
→ Safe Autonomy Charter
→ APEX Mirror
→ Iteration Automator + Benefit Governor
→ Evidence / GitHub Auto-Capture
→ Learning Center and other modules
→ Measured Improvement
```

## What Is Not Claimed

No claim is made that full autonomous execution, deployed human benefit, physical autonomy, public identity/likeness use, or unreviewed external source content is operationally verified.
