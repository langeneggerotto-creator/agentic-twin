# 02 APEX Foresight Engine

Shortcut: CRYSTAL BALL + APEX + QUALITY + INFINITY

## Purpose

The APEX Foresight Engine turns future-facing ideas into testable options, risks, assumptions, and next actions. It is not fortune telling. It is structured uncertainty management.

## Core Law

Do not predict the future as certainty. Map possible futures, test assumptions, and choose the smallest wise next move.

## What It Does

1. Captures the vision.
2. Lists plausible futures.
3. Separates evidence from assumptions.
4. Finds risks and early warning signals.
5. Builds decision options.
6. Selects the next smallest useful action.
7. Adds rollback and review triggers.

## Required Output Shape

```json
{
  "foresight_engine": {
    "vision": "...",
    "possible_futures": [],
    "key_assumptions": [],
    "early_warning_signals": [],
    "decision_options": [],
    "recommended_next_step": "...",
    "rollback_trigger": "...",
    "truth_status": {
      "VERIFIED": [],
      "INFERRED": [],
      "ASSUMED": [],
      "UNKNOWN": []
    }
  }
}
```

## Use Cases

| Use Case | Example |
|---|---|
| Product direction | Which APEX module should move next? |
| Repository planning | What folder or app should be promoted? |

| Risk control | What could fail before users notice? |
| Human development | What next step gives growth without overwhelm? |
| AI capability design | What power increase requires a matching control increase? |

## Foresight Gates

| Gate | Question | Required Result |
|---|---|---|
| Vision Gate | What future are we trying to create? | Clear enough to act |
| Evidence Gate | What do we actually know? | Labeled truth status |
| Assumption Gate | What are we guessing? | Explicit assumptions |
| Risk Gate | What could go wrong? | Early warning signals |
| Option Gate | What are the real choices? | At least 3 options |
| Control Gate | Can the user reverse or redirect? | Rollback trigger |
| Action Gate | What is the next smallest move? | One next action |

## Relationship to Heart Core

Foresight must never justify increasing system power faster than human understanding and control. Heart Core remains the governor.

## Minimal Law

See futures. Label uncertainty. Choose wisely. Move small.
