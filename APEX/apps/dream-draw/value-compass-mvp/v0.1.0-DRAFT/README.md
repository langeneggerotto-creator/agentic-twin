## Product Identity

**Dream Draw** is the user-facing application that helps a person make a dream, challenge or desired direction visible and move toward it through one meaningful next action.

**🅾️♾️ Value Compass** is the underlying directional insight engine. It is not a generic quote app. It exists to answer: given what the person wants, what they can do, what constrains them and how much time they have, what is the highest-value next use of their time?

## Preserved Canon

- Visible inputs: horizon, dream/aim, current state, capability and constraint.
- Direction output: **Best move · Why now · Watch out**.
- The card is a **micro-navigation instrument** combining emotional force, directional clarity and structural intelligence.
- Public-facing guides use first names only: Nola / Rowan / Sienna / Zara / Mira.
- The system guides without coercing, resonates without manipulating and does not pretend certainty.
- Static-card and motion-story outputs remain separable artifacts sharing one principle engine.

## Included v0.1 Capability

- One-screen browser interface.
- Local-only dream intake.
- Deterministic mode/guide selection.
- H0–H5 pathway bridge.
- Directional card, image-prompt and 3 × 10-second motion-story specification.
- Local user feedback signal recording.
- JSON evidence export.

## Not Included Yet

- Cloud storage, login or user profile database.
- Avatar rendering.
- Proven learning, behavior or outcome benefit.
- Production deployment authority.
