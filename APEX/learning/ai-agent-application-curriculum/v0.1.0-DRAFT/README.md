# APEX AI Agent-to-Application Curriculum — 0D to 11D

**Version:** v0.1.0-DRAFT  
**Status:** DRAFT / GITHUB-CAPTURED FOUNDATION  
**Purpose:** A proof-based, self-paced curriculum for understanding and building with ChatGPT prompts, agents, tools, code, GitHub, dashboards, automation, digital twins, testing, deployment and governed improvement.

## Key Decision

The earlier beginner curriculum is classified as **0D Orientation**. This directory expands it into a complete **0D → 11D ladder**. There are no week-based or time-based advancement requirements: progress is earned by demonstrated capability and recorded evidence.

## Contents

- `CURRICULUM_0D_TO_11D.md` — the full ladder and proof gates.
- `GITHUB_CAPTURE_PROTOCOL.md` — rules for preserving lessons, artifacts, evidence and handoffs.
- `PROGRESS_AND_EVIDENCE_LEDGER.md` — the advancement record template.
- `manifest.json` — artifact and commit register for this version.

## Truth Boundary

This curriculum is now a documented build artifact. It does not prove that a learner, module or system has passed a level until its required capability, evidence, review result and GitHub record are captured.

## Starting Practical Path

The first practical learner journey is **0D → 3D using APEX ARX Control Center and the GPU Telemetry module**:

1. Understand the system map.
2. Write one bounded prompt.
3. Route the task to the right agent/tool.
4. Run one safe software action.
5. Record the result and preserve it in GitHub.
